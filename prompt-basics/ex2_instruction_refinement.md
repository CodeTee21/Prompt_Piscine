# Objective: Convert vague requests into precise prompts.

    Start with a vague request like: “Tell me about AI.”

    Refine it step by step into a clear instruction, e.g.,

        “Explain AI in simple terms for beginners.”

        “Summarize the main AI techniques in 5 bullet points.”

# Vague request
Prompt: Tell me about AI.
Output: AI is a technology that allows computers to perform tasks that normally require human intelligence such as learning, problem solving, and decision making.

# Refined prompt 1
Prompt: Explain AI in simple terms for beginners.
Output: AI means teaching computers to think and learn like humans so they can recognize pictures, understand speech, and answer questions.

# Refined prompt 2
Prompt: Summarize the main AI techniques in 5 bullet points.
Output:

1. Machine learning

2. Deep learning

3. Natural language processing

4. Computer vision

5. Robotics 
# Compare outputs and note differences.
The vague request gives a general answer.
The clearer prompt gives an easy-to-understand answer.
The specific prompt gives a short and organized answer.
